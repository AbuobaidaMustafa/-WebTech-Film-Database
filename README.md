# WebTech Film Database

Search for films and TV series using the OMDb API, view details and write a review.

Built with HTML, CSS, Bootstrap 5 and JavaScript.

## Before you start
1. Get a free API key from https://www.omdbapi.com/apikey.aspx (it is emailed to you, click the link to activate it).
2. Open `js/script.js` and replace `YOUR_API_KEY` with your key.

## Files
- `index.html` - the page
- `css/style.css` - my styles
- `js/script.js` - search, film details and review form
- `images/` - logo and "no poster" image
